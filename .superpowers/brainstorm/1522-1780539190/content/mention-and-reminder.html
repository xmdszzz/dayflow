🔔 提醒系统

模块 设计
轮询引擎 Main Process 中 setInterval(30秒)
查询: SELECT * FROM tasks WHERE status='pending' AND notified=0 AND datetime(date||' '||time) <= datetime('now', '+10 minutes')
一次查出所有 10 分钟内到期的未提醒任务
通知触发 new Notification({ title: '⏰ 10分钟后', body: '项目评审会 @ 3号会议室 · 张总', silent: false })
点击通知 → 聚焦应用窗口 + 跳转到 Today 视图 + 高亮该任务
notified 字段设为 1（不重复提醒）
提醒时间 默认 10 分钟前
后续可在 Settings 中自定义: 5/10/15/30 分钟
存入 config 表: reminder_minutes = 10
系统托盘 应用关闭 → 最小化到托盘
托盘图标保持提醒服务运行
右键菜单: 显示窗口 / 今日任务(N) / 退出
左键双击 → 显示窗口
开机启动 可选: electron 的 app.setLoginItemSettings({ openAtLogin: true })
Settings 中开关控制

[
  { role: "system", content: `
    你是日程管理助手。使用 function calling 操作用户的日程。
