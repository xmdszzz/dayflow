Task-Anchored Chat — 每条消息都属于一个 Task Node

任务节点 → 消息挂载 → 关闭/过期即折叠

🔗 核心模型

每个 Task 节点下挂了一条或多条 Chat Message
Task Node: "项目评审会" (id: t-001, status: pending) ├── msg-001 [user] "明天上午9点跟张总在办公室开项目评审会" ├── msg-002 [assistant] "已添加：6月5日 09:00 张总 项目评审会" ├── msg-003 [user] "改到10点吧，地点换到3号会议室" └── msg-004 [assistant] "已修改：6月5日 10:00 张总 项目评审会 @ 3号会议室" Task Node: "喝咖啡" (id: t-002, status: done) ← 已完成 ├── msg-005 [user] "下午2点跟小李去星巴克喝咖啡" 🔥 folded └── msg-006 [assistant] "已添加：..." 🔥 folded Task Node: "健身" (id: t-003, status: pending) ├── msg-007 [user] "晚上8点去健身房练腿" └── msg-008 [assistant] "已添加：6月4日 20:00 健身"

📊 数据模型

tasks 表 (扩展)
CREATE TABLE tasks (
  id         TEXT PRIMARY KEY,
  date       TEXT NOT NULL,
  time       TEXT NOT NULL,
  place      TEXT DEFAULT '',
  person     TEXT DEFAULT '',
  event      TEXT NOT NULL,
  status     TEXT DEFAULT 'pending',
  chat_count INTEGER DEFAULT 0,  -- 挂载的消息数
  notified   INTEGER DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
chat_messages 表 (重构)
CREATE TABLE chat_messages (
  id         TEXT PRIMARY KEY,
  task_id    TEXT NOT NULL,     -- FK → tasks.id
  role       TEXT NOT NULL,
  content    TEXT NOT NULL,
  tool_calls TEXT,
  created_at TEXT NOT NULL,

  FOREIGN KEY (task_id) REFERENCES tasks(id)
);

🔄 消息流转规则

场景 触发条件 行为
新建任务 用户输入首条消息，LLM 识别为 add_task ① LLM 调用 add_task → 创建 Task Node
② 这条 user 消息 + assistant 回复 → 挂载到新 task_id
③ task.chat_count = 2
修改/查询已有任务 用户提到已有任务，LLM 识别为 update/query ① LLM 返回 target_task_id
② 消息挂载到该 task_id
③ task.chat_count += 1
任务完成/取消 用户手动 ✓ 或 LLM 调用 delete_task ① task.status = 'done' | 'cancelled'
② 该 task 下的 所有消息立即折叠
③ 折叠摘要存入 chat_memory
④ 下次 buildContext 不再包含这些消息
任务过期 任务时间 < 当前时间 且 status=pending ① ReminderService 检测到过期 → 通知 Renderer
② 用户可手动确认完成/忽略
③ 确认后 → 同上折叠流程
④ 未确认的过期任务 → 保留但降权显示，消息仍折叠

🧠 ContextBuilder 重构

只收集 status=pending + 未过期 task 的消息
function buildContext(userMessage, currentTaskId) {

  // SQL: SELECT cm.* FROM chat_messages cm
  //      JOIN tasks t ON cm.task_id = t.id
  //      WHERE t.status = 'pending'
  //        AND (t.date > today OR (t.date = today AND t.time > now))
  //      ORDER BY cm.created_at DESC
  //      LIMIT 20

  const activeMessages = db.getActiveTaskMessages(20);
  // ↑ JOIN 自动过滤掉已完成/已过期 task 的所有消息

  // 当前正在操作的 task 的消息（如果不在 active 窗口里，单独注入）
  const currentTaskMsgs = currentTaskId
    ? db.getMessagesByTask(currentTaskId)
    : [];

  // 折叠摘要：已完成/过期 task 的压缩信息
  const foldedSummary = `已完成任务: 项目评审会(2条消息), 喝咖啡(2条消息)`;

  return [
    { role: 'system', content: systemPrompt },
    { role: 'system', content: foldedSummary },   // 极简
    ...activeMessages,                                 // 只含活跃 task 的消息
    ...currentTaskMsgs,                                // 当前 task 完整上下文
    { role: 'user',   content: userMessage },
  ];
}
