🔧 全部 Tool 定义

Tool Name 分类 Parameters Handler 做的事 Returns
add_task 数据 date, time, place, person, event 生成 UUID → INSERT INTO tasks
创建关联 chat_messages 记录		 { task_id, task_summary }
update_task 数据 task_id, + 任意可选字段 UPDATE tasks SET ... WHERE id=task_id
检查 task 是否存在且 status=pending		 { task_id, changes, new_summary }
delete_task 数据 task_id UPDATE tasks SET status='cancelled'
触发该 task 的消息折叠		 { task_id, deleted_summary }
query_tasks 数据 date (可选), date_range (可选), status (可选) SELECT * FROM tasks WHERE ...
返回匹配的任务列表		 { tasks: [...], count }
get_now 系统 — (无参数) new Date() → 格式化返回 { datetime: "2026-06-04 15:30", weekday: "星期四", week: "W23" }
confirm_with_user 交互 question, options[] 不是真正的"执行"
而是向 Renderer 发送确认请求
等待用户选择后继续		 { user_choice, confirmed }
complete_task 数据 task_id UPDATE tasks SET status='done'
触发折叠 + 压缩		 { task_id, event }

🔄 完整调用链路（以 update_task 为例）

用户说"改到3点" → LLM 决策 → Tool 执行 → 回复

Step 1: Renderer → Main (IPC 'chat:send')
{ userMessage: "@项目评审会 改到下午3点", explicitTaskId: "t-001" }

Step 2: ContextBuilder 组装 messages + tools 定义
messages = [systemPrompt, activeTasks, activeMessages, userMsg]
tools    = [add_task, update_task, delete_task, query_tasks, get_now, complete_task, confirm_with_user]

Step 3: DeepSeek API 调用
→ choices[0].message.tool_calls = [{
    id: "call_abc",
    function: { name: "update_task", arguments: '{"task_id":"t-001","time":"15:00"}' }
}]

Step 4: ToolRegistry.execute("update_task", {task_id:"t-001", time:"15:00"})
→ db.prepare("UPDATE tasks SET time='15:00', updated_at=? WHERE id=?").run(now, "t-001")
→ 插入一条 assistant 消息（含 tool_call 信息）到 chat_messages，task_id=t-001
→ 返回 { success: true, task_id: "t-001", changes: {time: "15:00"} }

Step 5: 结果送回 DeepSeek，生成自然语言回复
→ "已修改：项目评审会改为 6月5日 15:00 @ 3号会议室"

Step 6: Main → Renderer 返回完整结果
→ 聊天面板追加 assistant 消息
→ 日历视图刷新（taskStore.loadTasks 重新查询）

🧩 Tool Registry 代码结构

Main Process · src/main/tools/
// src/main/tools/registry.ts
interface ToolDefinition {
  name: string;
  description: string;        // 给 LLM 看的功能描述
  parameters: JSONSchema;     // OpenAI function calling 格式
  handler: (args: any) => Promise<any>;  // 实际执行函数
  requiresConfirmation?: boolean;  // delete 操作需要二次确认
}

class ToolRegistry {
  private tools: Map<string, ToolDefinition> = new Map();

  register(tool: ToolDefinition) { ... }      // 注册一个 tool
  getOpenAITools() { ... }                    // 转为 OpenAI tool 格式发给 API
  async execute(name: string, args: any) { ... }  // 执行 tool handler
}

// 初始化时注册全部 tool
registry.register(addTaskTool);      // → handler 内调用 db.ts
registry.register(updateTaskTool);   // → handler 内调用 db.ts
registry.register(deleteTaskTool);   // → requiresConfirmation = true
registry.register(queryTasksTool);   // → handler 内调用 db.ts
registry.register(getNowTool);       // → handler 内调用 new Date()
registry.register(completeTaskTool); // → handler 内调用 db.ts + 折叠逻辑
registry.register(confirmTool);      // → 暂停，等待用户交互
